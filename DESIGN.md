# SalonFlow Design Spec

## Ranglar
- Primary: #6C5CE7 (tugmalar, aktiv holatlar)
- Background: #F8F9FD
- Card background: #FFFFFF
- Text primary: #1A1D29
- Text secondary: #8B90A0
- Success: #00B894, Danger: #FF6B6B
- Border: #E8EAF2

## Typography
- Font: Inter
- H1: 24px semibold, H2: 18px semibold
- Body: 14px regular, Caption: 12px

## Spacing & shakl
- Card padding: 20px, border-radius: 16px
- Sahifa padding: 24px, elementlar orasi: 16px
- Tugma: height 44px, radius 12px
- Sidebar kengligi: 240px

## Komponentlar
### StatsCard (dashboard)
- Oq karta, chapda icon (40x40, rangli fon, radius 10)
- O'ngda: qiymat (24px bold) + label (12px secondary)

### BookingCard (appointments)
- Chapda mijoz avatari (44px, doira)
- O'rtada: ism (14px medium) + xizmat nomi (12px secondary)
- O'ngda: vaqt (14px) + status badge
- Status badge: pill shakl, Success/Warning/Danger ranglar
